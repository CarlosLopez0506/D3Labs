Collection of D3.js visualization exercises, from basic primitives to interactive and animated charts. Each folder is a self-contained lab with its own dataset and rendering logic.

---

## Labs

| Lab | Concept |
|-----|---------|
| `D3-Basic` | SVG primitives, selections, data binding |
| `D3-Scales` | Linear, ordinal, and band scales |
| `D3-Margins_Groups_Axes_Labels` | Chart margins convention, axes, labels |
| `D3-Line` | Line chart with path generators |
| `D3-Area` | Area chart with fill |
| `D3-Pie_Donut` | Pie and donut charts with arc generators |
| `D3-Stacked` | Stacked bar charts with `d3.stack` |
| `D3-Buildings` | Custom bar rendering |
| `D3-Transitions` | Enter/update/exit pattern with animated transitions |
| `D3-Update` | Dynamic data updates and DOM reconciliation |
| `D3-Loading_Data` | CSV/JSON loading with `d3.csv` / `d3.json` |
| `D3-Event_Handling` | Mouse events, tooltips |
| `D3-Variable_As_Data` | Binding complex objects as data |
| `D3-Leaf_Project` | Applied project — data-driven layout |
| `D3-Star_Lion` | Applied project — custom visual composition |

## Running a Lab

Each lab is a standalone HTML file. Open `index.html` in any browser — no build step required.

```bash
cd D3-Line
open index.html
```
